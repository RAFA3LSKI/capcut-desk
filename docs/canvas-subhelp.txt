===== auth
Usage:
  dreamina-canvas auth [flags]
  dreamina-canvas auth [command]

Available Commands:
  account     Read the currently signed-in account
  login       Sign in to Dreamina Canvas
  logout      Sign out of the current profile
  refresh     Refresh the current sign-in credentials
  status      Read local sign-in state
  wait        Wait for an existing sign-in authorization

Flags:
  -h, --help   Show help for dreamina-canvas auth

Global Flags:
      --format string     Output format: json or table
      --non-interactive   Disable interactive prompts
      --profile string    Local sign-in state profile (default "default")
      --yes               Approve permitted operations without an interactive prompt

Use "dreamina-canvas auth [command] --help" for more information about a command.

===== workflow
Usage:
  dreamina-canvas workflow [flags]
  dreamina-canvas workflow [command]

Available Commands:
  cancel       Request cancellation of a workflow run (write)
  capabilities Show workflow capabilities and limits (read-only)
  confirm      Approve a quote ceiling and get a short-lived confirmation token (write)
  get          Show the full view of a workflow run (read-only)
  list         List workflow runs in a project (read-only)
  quote        Save a quote plan without running the workflow or charging credits
  run          Start a workflow run (write; replay with the same submitId to resume)
  template     Workflow template discovery and instantiation
  wait         Wait for a terminal workflow run; exit 20 on timeout, rerun to resume waiting

Flags:
  -h, --help   Show help for dreamina-canvas workflow

Global Flags:
      --format string     Output format: json or table
      --non-interactive   Disable interactive prompts
      --profile string    Local sign-in state profile (default "default")
      --yes               Approve permitted operations without an interactive prompt

===== node
Usage:
  dreamina-canvas node [flags]
  dreamina-canvas node [command]

Available Commands:
  confirm     Approve a credit ceiling for the specified nodes and return a short-lived token
  create      Create typed canvas nodes without starting generation
  cutout      Cut out images
  delete      Delete a batch of nodes after approval; groups are not supported
  edit        Edit saved typed canvas nodes without starting generation
  find        Find nodes by filter and return locator fields only (nodeId/type/title/status/tags)
  interpolate Interpolate videos
  promote     Promote a sample into a final video
  quote       Estimate credits for the specified nodes before running them
  run         Run the specified nodes
  show        Read views of the specified nodes
  upscale     Upscale generated images or videos into new nodes

Flags:
  -h, --help   Show help for dreamina-canvas node

Global Flags:
      --format string     Output format: json or table
      --non-interactive   Disable interactive prompts
      --profile string    Local sign-in state profile (default "default")
      --yes               Approve permitted operations without an interactive prompt
