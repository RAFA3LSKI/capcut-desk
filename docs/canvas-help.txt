Usage:
  dreamina-canvas [flags]
  dreamina-canvas [command]

Available Commands:
  auth        Manage sign-in and authentication state
  canvas      Manage canvases
  completion  Generate the autocompletion script for the specified shell
  director    Author, synchronize and export Director Stage projects
  help        Help about any command
  model       Query generation models and their callable specifications
  node        Create, edit, delete, read, or run typed canvas nodes
  operation   Inspect or wait for recoverable operations
  resource    Query, upload, and download canvas resources
  schema      Return the command contract for this artifact
  version     Return version and build information
  voice       Query voices available for audio generation
  workflow    Canvas workflow quotes, runs, and templates

Flags:
      --format string     Output format: json or table
  -h, --help              Show help for dreamina-canvas
      --non-interactive   Disable interactive prompts
      --profile string    Local sign-in state profile (default "default")
  -v, --version           Show version information
      --yes               Approve permitted operations without an interactive prompt

Use "dreamina-canvas [command] --help" for more information about a command.
